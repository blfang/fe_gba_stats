# Fire Emblem GBA Stat Distributions

Compute and compare stat distributions for any two characters from the Game Boy Advance Fire Emblem games — FE6: Binding Blade, FE7: Blazing Blade, and FE8: Sacred Stones. Configure levels, promotions, and growth modifiers, then view side-by-side stat cards and an overlaid radar plot showing average, median, 90th percentile (blessed), and 10th percentile (cursed) values.

## Features

- Select any character from FE6, FE7, or FE8 with support for multiple game variants and promotion branches
- Configure level, first-tier promotion, second-tier promotion, hard mode bonuses, and adjusted growth rates
- Compare two units side-by-side with detailed stat cards and an overlaid radar plot
- View stat distributions at average, median, 90th percentile (blessed), and 10th percentile (cursed) for each stat
- Pre-built example comparisons for quick exploration
- Share specific comparisons via URL
- FAQ section explaining growth calculation methodology
